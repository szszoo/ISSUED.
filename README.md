
# ISSUED

사진과 학생 정보를 입력해 나만의 학생증 이미지를 만드는 팬메이드 웹 스튜디오입니다.
실제 신분 확인용 학생증으로 사용할 수 없습니다.

## 주요 기능

- CLASSIC / HERITAGE 학생증 디자인과 프레임 색상 선택 (커스텀 HEX 컬러 포함)
- 사진 업로드, 위치·크기 조정, 사진 필터
- 앞·뒷면 미리보기와 카드 발급 애니메이션 및 효과음
- PNG, JPG, GIF 내보내기
- GIF는 앞면 1.5초, 뒷면 1.5초 표시하며 약 0.63초씩 뒤집혀 반복됩니다.
- PC, 태블릿, 모바일에 대응하는 반응형 화면

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다. 별도의 빌드나 설치 과정은 없습니다.
손글씨·세리프 웹폰트는 Google Fonts에서 불러오므로 인터넷 연결이 필요할 수 있습니다.

## GitHub Pages 배포

1. GitHub에서 저장소를 생성합니다.
2. 압축을 풀고 `index.html`과 `README.md`를 저장소 최상위(루트)에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다.
4. 브랜치를 `main`, 폴더를 `/(root)`로 설정하고 저장합니다.
5. 배포가 완료되면 `https://사용자이름.github.io/저장소이름/`에서 열 수 있습니다.
